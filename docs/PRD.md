# Todo 產品與驗收規格

本頁整理 **1.4.1 現行規則**，不因文件整理新增或刪除產品需求。[原始完整基線與 AC01–AC136](history/PRODUCT-BASELINE.zh-Hant.md)保留全部細項及歷史增量，仍供需求與驗收查核；舊段落的版本／格式與後來修訂衝突時，以本頁明示的最新規則及維護者後續明確要求為準。翻譯不改變需求優先順序。AC 是契約，不表示本輪已跑過測試；證據見 [TESTING](TESTING.md)。

## 1.5.0 開發增量

重複規則的結束日期須同時提供文字輸入與既有日曆選擇器；適用新增、轉換及本次與未來的規則編輯。日曆初始值按該欄保存的參考日期解析簡寫；空白或無效文字時使用該參考日，取消不覆寫文字，確認後回填 YYYY-MM-DD。原有結束日含當天及規則驗證不變。

放大圖片時，單擊實際圖片周圍的空白可關閉預覽；判斷須包含當前縮放與位移。圖片內單擊、縮放與拖曳不關閉，保留關閉按鈕及前後切換。目標正式 1.5.0，目前交付 1.5.0-dev03 測試包，待維護者確認。

未放大時，向左滑動預覽切下一張、向右切上一張，首尾不循環；放大後拖曳只移動圖片。前後箭頭仍可切換；每次換圖重設縮放與位移，旋轉保留已停留的圖片。圖片右上關閉改為叉號，前後切換使用箭頭。

常用明確操作使用圖示：加入圖片、選擇截止／學習開始／提醒時間、時間輸入／時鐘模式、篩選／多選／結束選取。提醒項目的「移除」、任務卡的編輯／移至垃圾桶／復原，以及任務、分類與標籤、垃圾桶與重複歷史的全選保留文字。保留數量、至少 48 dp 點擊範圍、三語無障礙說明與圖示長按提示；查詢期間多選外觀維持穩定，仍封鎖過期操作。主頁篩選及多選圖案依相鄰文字字級縮小，點擊範圍不縮小；結束選取勾號底色透明。建立、儲存、新增下一項、永久刪除與系列範圍保留文字與確認。

圖片箭頭採短動畫，連續點擊可接續或反向切換，不等前一動畫完全結束，仍限制首尾範圍。任務詳情展開與收起皆有淡入／淡出及高度動畫，收起過程保留內容至動畫完成；中途再次點擊可反向展開。

## 1.4.1 時間輸入

共用 24 小時制時間選擇器在輸入兩位有效小時後自動切換至分鐘；前導零、午夜及輸入與初始值相同的小時同樣適用。單位數、刪字及無效輸入不觸發換欄；空白欄位不可確認。保留手動換欄、時鐘模式共享值與取消不提交。維護者已於 2026-11-06 確認 1.4.1-dev02 並授權正式 1.4.1；來源與校驗值見 [發布確認](verification/approval-1.4.1.json)。 時間欄位中的數字、選取與游標應置中且不裁切；依實際字型與字級調整數字大小。未輸入時仍顯示預設 10:00；已有時間顯示原值，不以空白代替初始值。

## 產品範圍

原生 Android 個人待辦，最低 API 26，固定深色；繁中、簡中、英文及跟隨系統，無可用系統語言時回退英文。離線、本機儲存、無帳號／廣告／追蹤／App 自行雲端同步；原始碼與 APK 由 GitHub 提供。子任務、批次完成、一般附件、桌面 Widget、優先級、協作、AI 解析、日曆同步及 Play 商店發布不在已確認範圍。

## 導覽與日程（F01）

側欄含日程、未安排、已完成、分類與標籤、垃圾桶、設定；點 Todo 圖示／名字回日程。一般背景重入回日程，旋轉保留當次操作，外部系統選取器安全接續。

今日永遠顯示，無任務未來日期隱藏；跳空日期提供暫時錨點及當日新增。逾期投影到今日但原截止不變，不重複同項；只有日期過該日才逾期，有時刻依 Instant。未安排另有可快速到達區塊及獨立頁。有時刻先於只有日期，按截止早至晚；同截止按學習開始、建立時間及 ID 穩定排序。學習無截止仍在未安排，按開始日時排序，未填排後。

## 任務、草稿與圖片（F02）

名稱去空白後 1–200 字元，備註至多 20,000；全欄位直接分組顯示，不設二級詳細選單。全域新增無日期、日期入口預填。建立後關閉；新增下一項保留入口日期，其餘重設。失敗保留輸入，重試不得重建同 ID。離開新任務可保存草稿／捨棄／繼續；草稿不是任務、不排提醒、不在備份內。

點卡片原位展開；HTTP／HTTPS 連結可開啟。一般完成控制為圓形，作業／學習改用左側狀態圖示，文字共用對齊。完成提交後才開始短暫回饋／淡出／補位；跟隨系統動畫設定。空提示與任務卡片明顯區分，搜尋載入延後顯示，不因每字查詢切回主頁或閃爍多選。

備註先文字再圖片；系統選圖、縮圖／放大／縮放／切換、右上叉號移除。每項不設張數限制，原圖至多 25 MiB；輸出靜態 JPEG 最長邊 1536、至多 768 KiB，去原始 EXIF／位置、不改原圖。圖片隨草稿、模板、歷史及垃圾桶保存；無引用時清理。

## 分類、標籤與狀態（F03、F04）

一任務一分類、多標籤；名稱 1–50 字元，去空白及忽略大小寫防重複，分類與標籤可同名。管理頁長按拖拽、邊緣自動捲動、放手存排序，保留上／下移選單。另設批量刪除入口，預覽後同交易確認；刪分類先搬所有有效／完成／垃圾桶任務及系列，刪標籤只移連結。

未分類不可改名／刪除；作業及學習可改名不可刪，批選／全選亦排除。固定身分而非名稱啟用特殊功能。一般 OPEN／COMPLETED；作業未開始→進行中→完成未繳交→完成，完成未繳交仍待辦；學習未開始→進行中→完成。新作業／學習不可直接選完成，之後可完成及重開。移入作業須逐項選狀態，取消整批零寫入；作業進行中／完成未繳交移至學習為進行中，最終完成狀態保留。

學習表單順序：分類→學習狀態→開始日期（選填）→開始時間（選填）。開始時間須有開始日期；清日期亦清時間；記錄開始時區，移分類不丟已存資料。

## 日期與時區

日期提示 YYYY-MM-DD，接受 YYYY-MM-DD／YYYYMMDD／YYMMDD（20YY）／MMDD；時間提示 HH:mm，接受 HH:mm／HHmm，亦相容 HH-mm。MMDD 若月日或同日時刻早於輸入參考當下，取下一年；今天只有日期不跨年，明確年份不調整。目標年無效日期及手動 DST 缺口拒絕，過去截止警告後可確認保存。旋轉及非日期編輯不重解已預覽年份。

輸入／重新選定日期時間時捕捉 IANA 時區，僅改文字不換區。有時刻保存絕對意義，跨區日程按所在地日期投影並保留原值；日期-only 維持日曆日期。固定提醒保存 Instant，系列按保存時區的日曆規則。自動系列遇 DST 缺口順延，重複時刻取較早 offset。

## 重複（F05）

每日／每週／指定星期（一至日）／每月／每 N 天（1–3650）；無限／含結束日／總次數（含首次及已刪單次）。第一次截止日期留空為今天，並非學習開始日期。每月保留原日號，月底不足暫取月底。依日期補齊、不等前次完成，序號及游標不倒退，每槽唯一且可重試。

日程每系列至多一筆，優先最近逾期，否則最早待處理；其餘全部在「已完成→重複紀錄」，不混入一般完成分頁。過去／完成保留快照，不被模板改寫；新重複作業未開始，新學習選進行中只套首次。提供僅本次／本次及未來的明確預覽，過去／完成／已刪不重排；縮短規則保留唯讀取消紀錄，延長不重用舊槽。

停止只阻止新生成，保留既存提醒與任務。主頁及歷史可刪未來，預設停止並刪各系列時區今天之後的未完成，保留今天／過去／完成；含歷史須另選。單次刪除不停止系列；還原不倒退游標。

## 提醒（F06）

單項／系列最多 32 個。截止前數字＋分鐘／小時／天，預設 1 天；日期-only 基準可調，預設 10:00，不補截止時刻。固定日期時間可省略時間，採截止時刻或基準，保存後固定 Instant；相對提醒跟截止變動。系列可用日偏移或截止前模板，單次自訂／重設明確區分。保存後按觸發時刻自截止往前排列。

完成／刪除取消相關提醒，不補發大量過去點；通知完成只作用原 taskId。通知權限及精確鬧鐘能力分開管理，拒絕不阻止保存；缺精確能力警告並退回一般排程。開機／時間時區變更／重入校正，outbox 與取消佇列持久可重試。不得承諾強制停止／廠商省電下必達；實機矩陣仍待驗收。

## 搜尋與批次（F07）

每頁隔離的名稱／備註／分類／標籤連續子字串搜尋，忽略大小寫；多分類 OR，標籤全部／任一，文字＋分類＋標籤組間 AND。篩選取消不變更。全結果計數及全選包括未載入頁。長按多選，條件改變清選取、過期回應不恢復舊範圍；一般可移分類／加標籤／刪除，不批次完成。垃圾桶復原／永久刪除；重複總覽停／刪系列，系列內刪單次，排除唯讀規則取消項。確認凍結完整版本及成員，任一過期全拒絕，寫入失敗全回滾。

## 完成、垃圾桶及備份（F08、F09）

一般完成可重開，保留期限永久／30／90／365／自訂天，預覽後才改；不套用重複歷史。到期先進垃圾桶，從 deletedAt 起 30×24 小時可復原；系統延後清理不延長資格。整系列還原只帶回同次刪除的剩餘項，不復原更早單刪者；永久刪系列包含全部剩餘項，確認數量及範圍。復原／匯入寬限不改原完成時間。

備份格式 6／schema 10，讀格式 1–5，包含語言、圖片、垃圾桶、排序及一般設定，不含草稿、權限或平台鬧鐘身分。完整取代套用檔案資料與偏好；舊檔缺失偏好保留本機。合併按 ID 與真實修改時間、系列整組，垃圾桶與一般設定衝突明確選版本，不以同名判同項。驗證→預覽→同交易重驗／提交，失敗零部分寫入。完整限制見 [BACKUP-FORMAT](BACKUP-FORMAT.md)。

## 品質與驗收

Room／Repository／ViewModel 為持久資料及單向狀態來源；非破壞遷移、穩定 ID、revision 與原提醒取消資訊須保留。固定深色，狀態不只靠顏色，48dp 點按範圍、TalkBack／200% 字級為品質要求，未完成驗收不得宣稱達標。參考 10,000 任務／50,000 歷史的冷啟動 2 秒及常用搜尋／更新 500 ms 是目標，並非目前已驗收結果。

原始 AC01–126、AC127–134（學習開始／完整備份）及 AC135–136（學習三態／首次截止）保留於[完整基線](history/PRODUCT-BASELINE.zh-Hant.md)。後續圖片、受保護學習分類與三語增量按本頁及對應資料／備份契約核對。測試／真機／隔夜／大量資料缺口見 [KNOWN-ISSUES](KNOWN-ISSUES.md)；發布遵循[測試 APK 確認](../CONTRIBUTING.md#test-apks-and-release-approval)，不以 CI 成功代替維護者同意。
