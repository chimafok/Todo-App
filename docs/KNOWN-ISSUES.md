# 已知限制與驗收狀態

<p align="center">語言 / 语言 / Languages：<strong>繁體中文</strong> · <a href="zh-CN/KNOWN-ISSUES.md">简体中文</a> · <a href="en/KNOWN-ISSUES.md">English</a></p>

本頁對應 1.5.0。正式簽署及發布不代表以下未驗範圍已完成；實際結果見[驗證紀錄](TESTING.md)。

- **提醒**：尚未全面完成真機、長時間背景、隔夜、鎖屏及廠商省電策略驗收。強制停止、勿擾、通知／精確鬧鐘權限與背景限制可能延遲或阻止提醒；模擬器結果不保證所有手機可靠。
- **語言與無障礙**：支援繁中、簡中及英文，固定深色。語言從 App 設定選擇，尚未整合 Android 系統個別 App 語言頁。尚未經獨立母語審校，也未全面驗收 TalkBack、200% 字級、所有長字串組合或 RTL。已發出的通知及歷史快照不追溯重寫；使用者內容與授權原文不翻譯。
- **圖片**：每項不設張數上限，但單次系統選圖張數依 Android／供應商而定。原圖上限 25 MiB，轉為最長邊 1536、單張至多 768 KiB 的靜態 JPEG；不是原圖保存工具。HEIC、雲端照片與各家選圖器仍需實機確認。
- **備份**：格式 6／schema 10，包含圖片、語言、垃圾桶、排序及一般設定，可讀格式 1–5。JSON 為未加密明文且限 64 MiB；超過時拒絕，不略過圖片。1.3.1 及更舊版本不能讀格式 6。匯入不延長原垃圾桶期限，先看預覽並保留更新前備份。
- **大量資料效能**：精簡索引、完整結果 ID、批次選取與系列預覽仍可能隨資料量成長；部分整理／垃圾桶操作需要完整範圍。歷史 debug 軟體繪圖模擬器的 60,000 筆資料啟動中位數為 7.867 秒，捲動樣本為 79% jank，未達參考真機 2 秒／500 ms 目標。這是特定舊環境的量測，並非目前正式版的普遍表現，也未證明問題已解除。
- **不提供的功能**：帳號、App 自行雲端同步、自動下載更新、淺色模式、子任務、批次完成、一般檔案附件、桌面 Widget 或 Play 商店發布。

回報請提供 App／Android 版本、重現步驟與預期結果。請勿上傳真實備份或未遮蔽的私人內容。
