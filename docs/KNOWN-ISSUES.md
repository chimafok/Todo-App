# 已知限制與驗收狀態

- 專案持續開發中，尚未完成所有實機、TalkBack、長時間背景與隔夜提醒驗收。
- 手機廠商的省電、鎖屏、強制停止與權限策略可能延遲或阻止提醒；模擬器成功不代表全部手機可靠。
- 沒有帳號、雲端同步、自動更新、子任務、一般檔案附件或桌面 Widget；備份為未加密 JSON。
- 1.3.0使用備份格式5／schema9，含備註圖片、學習進度、垃圾桶、排序與一般設定；可讀格式1–4。1.3.0-dev01／dev02及更舊版本不能讀格式5，請保留更新前備份。還原前請看預覽，垃圾桶仍按原刪除日期到期。
- 備註圖片每項不設張數上限；系統選圖器單次張數仍依Android／供應商而定，可分批加入。圖片會壓縮為靜態JPEG（最長邊1536、單張768 KiB），不是原圖保存工具；含圖片備份仍限64 MiB，超過時會拒絕而不略過圖片。系統選圖器、HEIC等來源格式及雲端供應商相容性仍需在實際手機驗收。
- 大量資料的索引、完整搜尋結果 ID、系列預覽及批次選取仍可能成長；部分整理／垃圾桶操作需要完整範圍。
- 早期 debug 軟體繪圖模擬器的 60,000 筆資料啟動中位數約 7.867 秒，捲動樣本 79% jank；未達原參考真機 2 秒／500ms 目標。這是特定測試環境的歷史量測，不代表目前正式 APK 的所有裝置表現，也未證明問題已解除。
- 介面目前以繁體中文與固定深色提供。

回報請提供 App 版本、Android 版本、重現步驟與預期結果；不要上傳真實備份或未遮蔽的私人資料。
