# Security reporting

<p align="center">語言 / 语言 / Languages：<a href="../../SECURITY.md">繁體中文</a> · <a href="../zh-CN/SECURITY.md">简体中文</a> · <strong>English</strong></p>

The latest published version is maintained. Use GitHub Issues for ordinary bugs.

For vulnerabilities involving private data or exploitable details, use **Security → Advisories → Report a vulnerability** in this repository. If private reporting is unavailable, do not put attack details, passwords, keys or private data in a public issue. You may open a minimal issue without sensitive details to request a private reporting channel.

Provide the affected version, necessary reproduction steps and anonymized test data. Real task backups or an entire phone's data are not needed. No response deadline is guaranteed.

The official signing private key and passwords remain in the maintainer's secure environment. If source or download assets appear modified, stop installation and compare the release checksum and [public certificate fingerprint](SIGNING.md).
