# 已知限制与验收状态

<p align="center">語言 / 语言 / Languages：<a href="../KNOWN-ISSUES.md">繁體中文</a> · <strong>简体中文</strong> · <a href="../en/KNOWN-ISSUES.md">English</a></p>

本页对应 1.4.0。正式签署及发布不代表以下未验范围已完成；实际结果见[验证记录](TESTING.md)。

- **提醒**：尚未全面完成真机、长时间背景、隔夜、锁屏及厂商省电策略验收。强制停止、勿扰、通知／精确闹钟权限与背景限制可能延迟或阻止提醒；模拟器结果不保证所有手机可靠。
- **语言与无障碍**：支持繁中、简中及英文，固定深色。语言从 App 设置选择，尚未整合 Android 系统个别 App 语言页。尚未经独立母语审校，也未全面验收 TalkBack、200% 字号、所有长字符串组合或 RTL。已发出的通知及历史快照不追溯重写；用户内容与授权原文不翻译。
- **图片**：每项不设张数上限，但单次系统选图张数依 Android／供应商而定。原图上限 25 MiB，转为最长边 1536、单张至多 768 KiB 的静态 JPEG；不是原图保存工具。HEIC、云端照片与各家选图器仍需实机确认。
- **备份**：格式 6／schema 10，包含图片、语言、垃圾桶、排序及一般设置，可读格式 1–5。JSON 为未加密明文且限 64 MiB；超过时拒绝，不略过图片。1.3.1 及更旧版本不能读格式 6。导入不延长原垃圾桶期限，先看预览并保留更新前备份。
- **大量数据效能**：精简索引、完整结果 ID、批次选取与系列预览仍可能随数据量成长；部分整理／垃圾桶操作需要完整范围。历史 debug 软件绘图模拟器的 60,000 笔数据启动中位数为 7.867 秒，滚动样本为 79% jank，未达参考真机 2 秒／500 ms 目标。这是特定旧环境的量测，并非目前正式版的普遍表现，也未证明问题已解除。
- **不提供的功能**：账号、App 自行云端同步、自动下载更新、浅色模式、子任务、批次完成、一般文件附件、桌面 Widget 或 Play 商店发布。

反馈请提供 App／Android 版本、重现步骤与预期结果。请勿上传真实备份或未遮蔽的私人内容。
