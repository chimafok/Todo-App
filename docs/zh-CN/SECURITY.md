# 安全问题

<p align="center">語言 / 语言 / Languages：<a href="../../SECURITY.md">繁體中文</a> · <strong>简体中文</strong> · <a href="../en/SECURITY.md">English</a></p>

目前维护最新发布版本；一般问题可使用 GitHub Issues。

涉及私密数据或可被利用的漏洞，请使用本仓库 Security → Advisories → Report a vulnerability（私人漏洞反馈）。如果此入口不可用，请勿把攻击细节、密码、金钥或私人数据公开到 Issue；可先开不含敏感内容的 Issue，请维护者提供私人反馈方式。

请提供受影响版本、必要重现步骤与经去识别的测试数据。不需要真实任务备份或整部手机的数据。维护者确认前不保证回覆时程。

正式签章私钥与密码只留在维护者的安全环境。若来源或下载资产疑似被修改，先停止安装并比对 Release 的杂凑与公开凭证指纹。
