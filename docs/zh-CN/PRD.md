# Todo 产品与验收规格

<p align="center">語言 / 语言 / Languages：<a href="../PRD.md">繁體中文</a> · <strong>简体中文</strong> · <a href="../en/PRD.md">English</a></p>

本页整理 **1.4.0 现行规则**，不因文件整理新增或删除产品需求。[原始完整基线与 AC01–AC136](../history/PRODUCT-BASELINE.zh-Hant.md)保留全部细项及历史增量，仍供需求与验收查核；旧段落的版本／格式与后来修订冲突时，以本页明示的最新规则及维护者后续明确要求为准。翻译不改变需求优先顺序。AC 是契约，不表示本轮已跑过测试；证据见 [TESTING](TESTING.md)。

## 产品范围

原生 Android 个人待办，最低 API 26，固定深色；繁中、简中、英文及跟随系统，无可用系统语言时回退英文。离线、本机储存、无帐号／广告／追踪／App 自行云端同步；源代码与 APK 由 GitHub 提供。子任务、批次完成、一般附件、桌面 Widget、优先级、协作、AI 解析、日历同步及 Play 商店发布不在已确认范围。

## 导览与日程（F01）

侧栏含日程、未安排、已完成、分类与标签、垃圾桶、设置；点 Todo 图示／名字回日程。一般背景重入回日程，旋转保留当次操作，外部系统选取器安全接续。

今日永远显示，无任务未来日期隐藏；跳空日期提供暂时锚点及当日新增。逾期投影到今日但原截止不变，不重复同项；只有日期过该日才逾期，有时刻依 Instant。未安排另有可快速到达区块及独立页。有时刻先于只有日期，按截止早至晚；同截止按学习开始、建立时间及 ID 稳定排序。学习无截止仍在未安排，按开始日时排序，未填排后。

## 任务、草稿与图片（F02）

名称去空白后 1–200 字元，备注至多 20,000；全栏位直接分组显示，不设二级详细菜单。全域新增无日期、日期入口预填。建立后关闭；新增下一项保留入口日期，其余重设。失败保留输入，重试不得重建同 ID。离开新任务可保存草稿／舍弃／继续；草稿不是任务、不排提醒、不在备份内。

点卡片原位展开；HTTP／HTTPS 连结可开启。一般完成控制为圆形，作业／学习改用左侧状态图示，文字共用对齐。完成提交后才开始短暂回馈／淡出／补位；跟随系统动画设置。空提示与任务卡片明显区分，搜寻载入延后显示，不因每字查询切回主页或闪烁多选。

备注先文字再图片；系统选图、缩图／放大／缩放／切换、右上叉号移除。每项不设张数限制，原图至多 25 MiB；输出静态 JPEG 最长边 1536、至多 768 KiB，去原始 EXIF／位置、不改原图。图片随草稿、模板、历史及垃圾桶保存；无引用时清理。

## 分类、标签与状态（F03、F04）

一任务一分类、多标签；名称 1–50 字元，去空白及忽略大小写防重复，分类与标签可同名。管理页长按拖拽、边缘自动滚动、放手存排序，保留上／下移菜单。另设批量删除入口，预览后同交易确认；删分类先搬所有有效／完成／垃圾桶任务及系列，删标签只移连结。

未分类不可改名／删除；作业及学习可改名不可删，批选／全选亦排除。固定身分而非名称启用特殊功能。一般 OPEN／COMPLETED；作业未开始→进行中→完成未缴交→完成，完成未缴交仍待办；学习未开始→进行中→完成。新作业／学习不可直接选完成，之后可完成及重开。移入作业须逐项选状态，取消整批零写入；作业进行中／完成未缴交移至学习为进行中，最终完成状态保留。

学习表单顺序：分类→学习状态→开始日期（选填）→开始时间（选填）。开始时间须有开始日期；清日期亦清时间；记录开始时区，移分类不丢已存数据。

## 日期与时区

日期提示 YYYY-MM-DD，接受 YYYY-MM-DD／YYYYMMDD／YYMMDD（20YY）／MMDD；时间提示 HH:mm，接受 HH:mm／HHmm，亦相容 HH-mm。MMDD 若月日或同日时刻早于输入参考当下，取下一年；今天只有日期不跨年，明确年份不调整。目标年无效日期及手动 DST 缺口拒绝，过去截止警告后可确认保存。旋转及非日期编辑不重解已预览年份。

输入／重新选定日期时间时捕捉 IANA 时区，仅改文字不换区。有时刻保存绝对意义，跨区日程按所在地日期投影并保留原值；日期-only 维持日历日期。固定提醒保存 Instant，系列按保存时区的日历规则。自动系列遇 DST 缺口顺延，重复时刻取较早 offset。

## 重复（F05）

每日／每周／指定星期（一至日）／每月／每 N 天（1–3650）；无限／含结束日／总次数（含首次及已删单次）。第一次截止日期留空为今天，并非学习开始日期。每月保留原日号，月底不足暂取月底。依日期补齐、不等前次完成，序号及游标不倒退，每槽唯一且可重试。

日程每系列至多一笔，优先最近逾期，否则最早待处理；其余全部在「已完成→重复纪录」，不混入一般完成分页。过去／完成保留快照，不被模板改写；新重复作业未开始，新学习选进行中只套首次。提供仅本次／本次及未来的明确预览，过去／完成／已删不重排；缩短规则保留只读取消纪录，延长不重用旧槽。

停止只阻止新生成，保留既存提醒与任务。主页及历史可删未来，默认停止并删各系列时区今天之后的未完成，保留今天／过去／完成；含历史须另选。单次删除不停止系列；还原不倒退游标。

## 提醒（F06）

单项／系列最多 32 个。截止前数字＋分钟／小时／天，默认 1 天；日期-only 基准可调，默认 10:00，不补截止时刻。固定日期时间可省略时间，采截止时刻或基准，保存后固定 Instant；相对提醒跟截止变动。系列可用日偏移或截止前模板，单次自订／重设明确区分。保存后按触发时刻自截止往前排列。

完成／删除取消相关提醒，不补发大量过去点；通知完成只作用原 taskId。通知权限及精确闹钟能力分开管理，拒绝不阻止保存；缺精确能力警告并退回一般排程。开机／时间时区变更／重入校正，outbox 与取消伫列持久可重试。不得承诺强制停止／厂商省电下必达；实机矩阵仍待验收。

## 搜寻与批次（F07）

每页隔离的名称／备注／分类／标签连续子字串搜寻，忽略大小写；多分类 OR，标签全部／任一，文字＋分类＋标签组间 AND。筛选取消不变更。全结果计数及全选包括未载入页。长按多选，条件改变清选取、过期回应不恢复旧范围；一般可移分类／加标签／删除，不批次完成。垃圾桶恢复／永久删除；重复总览停／删系列，系列内删单次，排除只读规则取消项。确认冻结完整版本及成员，任一过期全拒绝，写入失败全回滚。

## 完成、垃圾桶及备份（F08、F09）

一般完成可重开，保留期限永久／30／90／365／自订天，预览后才改；不应用重复历史。到期先进垃圾桶，从 deletedAt 起 30×24 小时可恢复；系统延后清理不延长资格。整系列还原只带回同次删除的剩余项，不恢复更早单删者；永久删系列包含全部剩余项，确认数量及范围。恢复／导入宽限不改原完成时间。

备份格式 6／schema 10，读格式 1–5，包含语言、图片、垃圾桶、排序及一般设置，不含草稿、权限或平台闹钟身分。完整取代应用文件数据与偏好；旧档缺失偏好保留本机。合并按 ID 与真实修改时间、系列整组，垃圾桶与一般设置冲突明确选版本，不以同名判同项。验证→预览→同交易重验／提交，失败零部分写入。完整限制见 [BACKUP-FORMAT](BACKUP-FORMAT.md)。

## 品质与验收

Room／Repository／ViewModel 为持久数据及单向状态来源；非破坏迁移、稳定 ID、revision 与原提醒取消信息须保留。固定深色，状态不只靠颜色，48dp 点按范围、TalkBack／200% 字号为品质要求，未完成验收不得宣称达标。参考 10,000 任务／50,000 历史的冷启动 2 秒及常用搜寻／更新 500 ms 是目标，并非目前已验收结果。

原始 AC01–126、AC127–134（学习开始／完整备份）及 AC135–136（学习三态／首次截止）保留于[完整基线](../history/PRODUCT-BASELINE.zh-Hant.md)。后续图片、受保护学习分类与三语增量按本页及对应数据／备份契约核对。测试／真机／隔夜／大量数据缺口见 [KNOWN-ISSUES](KNOWN-ISSUES.md)；发布遵循[测试 APK 确认](CONTRIBUTING.md#test-apks-and-release-approval)，不以 CI 成功代替维护者同意。
