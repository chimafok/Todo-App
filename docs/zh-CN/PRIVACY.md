# 隐私与权限

<p align="center">語言 / 语言 / Languages：<a href="../../PRIVACY.md">繁體中文</a> · <strong>简体中文</strong> · <a href="../en/PRIVACY.md">English</a></p>

更新日期：2026-11-03（1.4.0）。

Todo 的任务数据存储在装置上的 App 私有空间，不设账号、广告、分析追踪或 App 自行执行的云端同步。目前正常 App 不宣告互联网存取权限。卸载或清除 App 数据会移除本机内容；请自行导出备份。

## 数据与文件

任务、备注文字与图片、分类、标签、截止时区、重复规则及提醒等数据在本机处理。系统通知可能在锁屏显示任务内容，显示方式由 Android 与你的通知设置管理。

备份经系统文件选择器读写，不要求广泛存储权限。导出 JSON 为未加密明文；选择云端文件供应商时，该供应商可能处理文件。App 停用 Android 自动备份／数据转移的任务数据，提供自行选择的 JSON 导出与预览还原。

App 私有缓存可能暂存导入／导出数据以接续操作；暂存有清理机制，不应视为可靠备份。格式 6 的 JSON 包含语言偏好、备注图片、垃圾桶、分类／标签排序与一般设置，因此可能保留已删除任务内容；不包含草稿及系统权限，详见[使用说明](USER-GUIDE.md#backup-and-restore)。

## 权限

| 权限／能力 | 用途 |
|---|---|
| 通知 | 在允许时显示任务提醒 |
| 精确闹钟 | 系统允许时较精确地安排提醒；缺少能力时提示并退回一般排程 |
| 开机完成 | 开机后校正符合条件的未来提醒 |
| 系统选取图片 | 只读取你选定的图片，复制并压缩后存入本机；不读取整个相册、不修改原图、不带入原始位置或 EXIF |
| 系统选取文件 | 只读写你明确选定的导出或导入文件 |

不要求整个相册或广泛存储权限，不读取联络人、个人信息或其他 App 私有内容。图片只在你透过系统选图器选定后读取；若来源是云端照片供应商，该供应商可能需下载你选定的图片。Todo 自身不将图片上传网络。

## GitHub 与问题反馈

下载页、问题反馈及贡献由 GitHub 提供，适用 GitHub 自身政策。请勿公开真实任务备份、装置识别码、密码或金钥；必要截图先遮蔽私人内容。安全问题请参阅[安全反馈](SECURITY.md)。
